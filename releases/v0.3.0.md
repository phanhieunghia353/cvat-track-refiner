# Experimental v0.3.0 — observed-surface reconstruction core

The default workflow is now **Lõi dựng hình + box chung**. It reconstructs observed LiDAR surface samples with per-frame poses/provenance, a fixed reference, normal-based local registration, rank/held-out checks and connected-group validation. It does not invoke the old point-extents box estimator. Single-frame regions are retained; neighbor/ground context is masked and inspectable.

Use the CPU Canvas 3D/orthographic viewer to inspect sources, hide frames, exclude/reinclude observations, or pin/change the pre-label reference. Optionally edit a shared xyz/yaw/LWH box numerically and explicitly create a proposal; rigid transforms project it into trusted frames. The original backup/native Commit/Undo/unrelated-label audit boundary remains. Unknown samples block propagation; unsampled intervals can be interpolated and must be inspected.

Includes local snapshot/diagnostic exports, replay script, comments and user/architecture documentation. The legacy fitter remains available separately. No runtime model, CDN, specialized GPU, server integration, wider extension permission or CVAT page reload was added.

66 automated tests passed, including core PCD/worker integration and core → user box → audited native Commit in mocks. UI/worker tested in an in-app browser with synthetic data. The favorable eight-frame synthetic fixture reduced mean center error 0.1074 → 0.00988 m; this is not real-data accuracy.

**Limitations:** first local reconstruction workbench; observed surfels, not a closed mesh or completed hidden shape. No semantic separation of body/mirrors/background, full global pose graph, 6-DOF fitting or 3D box drag handles. Hosted CVAT/Brave and the user's real scan have not been end-to-end verified. Numerical confidence checks are not correctness probabilities.

Install the `brave` ZIP; use `source` for code/tests. Existing releases are preserved. Read `CORE-USER-GUIDE.md` before applying.
