# CVAT Track Refiner v0.3.2 — Identity and order protection

## English

Published experimental release with extension ZIP, source ZIP and SHA256 checksums in **Assets**. Earlier versions could replace a track and change its ID, shifting client numbering after reload. v0.3.2 edits the existing native track, verifies server/native identity before writing and audits all annotations after every edited frame. A mismatch or unverifiable outcome blocks further Apply; it is not automatically retried.

- Per-attempt backups/journals are persisted and read back before editing; previous backups are retained. Unresolved attempts remain blocked across panel reopening.
- Read-only post-Save ID verification and recovery-log export. The extension does not call server Save, write annotation HTTP APIs or reload CVAT; CVAT Auto save remains in control.
- The implementation passed 96 automated tests, including 80-object Save/reload simulation and an official CVAT import-method contract. These do not certify the user's customized host. Audits detect side effects after native calls, not before every possible host behavior.
- IDs already changed by old builds are not automatically restored. Unsupported inventories, unreadable server IDs, unsaved top-level objects or unavailable backup storage prevent Apply.

**Update in place:** copy the contents of the new extension folder into the exact existing installation directory, then Reload the extension card at `brave://extensions`. Do not uninstall or load from a new path, so old backups remain accessible. No CVAT page reload is required.

## Tiếng Việt

Bản sửa khẩn cấp cho đường Apply. Bản cũ thay track làm ID được cấp lại và kéo theo thứ tự client ID sau reload. v0.3.2 giữ native track, bắt buộc kiểm tra ID/thứ tự server trước ghi và audit toàn bộ annotation sau từng frame. Nếu lệch hoặc không thể xác minh thì khóa Apply, không thử ghi lại.

- Backup và log riêng từng lượt, đọc lại storage trước sửa; giữ nguyên backup cũ. Lượt chưa xác minh vẫn chặn sau mở lại panel.
- Nút **Kiểm tra ID sau Save (chỉ đọc)** và **Tải lịch sử backup/audit**. Tool không gọi Save, không API ghi annotation, không reload CVAT; Auto save vẫn thuộc CVAT.
- 96 tests gồm trường hợp 80 object Save/reload, tái hiện lỗi replacement đổi thứ tự qua phương thức import CVAT chính thức, lỗi nhãn ngoài phạm vi và ID server/keyframe. Đây là contract tests/mô phỏng, chưa kiểm chứng trực tiếp host CVAT tùy biến của người dùng. Audit phát hiện tác dụng phụ sau native call đầu tiên, không phải bảo đảm tuyệt đối trước mọi host.

**Cập nhật tại chỗ để giữ backup:** tải ZIP có chữ brave, chép nội dung vào đúng thư mục extension đã cài rồi bấm Reload trên thẻ extension ở brave://extensions. Không gỡ extension, không Load unpacked từ đường dẫn mới, không cần reload tab CVAT. Đóng panel trước rồi mở lại và Đọc job.

ID đã đổi từ bản cũ chưa được khôi phục bởi bản này. Không có thao tác tự import/ghi đè toàn bộ job. Nếu không đọc được ID server, có object mới chưa Save, ID phiên không khớp thứ tự nạp lại, storage đầy hoặc lượt lỗi chưa xác minh thì chỉ xem trước.

Gói brave là extension; source gồm code/comment, tests và docs. SHA256 đi kèm để kiểm tra file tải về. Không chứa dữ liệu annotation/point cloud riêng của người dùng.
