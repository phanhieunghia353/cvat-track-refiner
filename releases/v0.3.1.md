# Experimental v0.3.1 — Apply without replacing the track

Fixes the v0.3.0 behavior where Apply removed the selected track and added a replacement, changing its CVAT client ID. The replacement writer is removed. Apply now edits the existing native ObjectStates, keeping the client ID, track server ID and existing keyframe IDs in both validation and audit. Missing native capabilities abort before any write; there is no Commit/import fallback.

Dedicated restore covers the whole batch, including long batches beyond CVAT's bounded history: it uses audited native Undo when all actions remain, otherwise restores original geometry and removes only newly inserted keys on the same track. In the latter case CVAT's edited-source mark may remain; the tool reports it. Native Ctrl+Z can undo just one frame. Partial failures are not retried automatically.

75 tests pass, including same-ID Apply/Undo/Redo, unrelated annotations, normalized-angle reads, a 60-frame/32-history case, sparse 70-key restoration and partial-save failure. These are contract fixtures; the hosted CVAT job was not mutated during development. Reconstruction algorithms are unchanged.

No CVAT reload or automatic server Save is added. CVAT Auto save still follows its existing settings. Old releases remain available but use v0.3.1 for identity-preserving Apply.

Download the `brave` ZIP, extract and Load unpacked in Brave. Read CORE-USER-GUIDE.md, particularly restore/source and Auto save behavior.
