# Experimental v0.2.1 — final per-frame box validation

Fixes a gap where final recentering could move a box after registration acceptance without checking the resulting per-frame coverage. Final boxes now undergo coverage and leave-one-out loss/support checks; unsafe observations retain complete pre-label geometry and stop size/pose propagation across them. Preview and draft share the same option-specific geometry decisions.

Adds detailed audits, an explicit **Tải chẩn đoán có điểm crop** download, and a local replay script. Ordinary summary reports do not contain enough data to reproduce point-cloud fitting. Diagnostics remain on the user's machine unless explicitly shared.

53 automated tests passed, including a synthetic lateral-shift/shrink regression and local export/replay. The actual private problematic frame has not been rerun because its point coordinates were unavailable. This remains an experimental prerelease, not an accuracy guarantee.

No CVAT annotation REST writes, reload requirement, or automatic Save were added. Native Apply/Undo and backup behavior are unchanged. Download the `brave` ZIP for installation, or `source` for code/tests. Prior release assets are preserved.
